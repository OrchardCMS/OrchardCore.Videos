# Shortcodes: Embed Images and Links in Your Text

**YouTube:** not published yet · **Length:** 3:49 · **Feature:** OrchardCore.Shortcodes ([documentation](https://docs.orchardcore.net/en/latest/reference/modules/Shortcodes/))

A video for editors and site owners. It explains what a shortcode is, then uses the built-in image and asset_url
shortcodes in the editor of an article: Insert Media, the options of the image shortcode, and the Available Shortcodes
dialog. It ends with where shortcodes work. The title, description, tags and chapters YouTube shows are in the video's
metadata file.

## Recording it again

The video is recorded on a **fresh site** with fake data only, so it needs no mask script. The recording plan
(recording-plan.md) says everything a person needs: read it first, and then OPEN-QUESTIONS.md, which lists what to
check on the running site.

1. Build the Orchard Core web project and start it on an empty data folder outside both repositories, provisioned by
   Auto Setup with the Blog recipe, the site name Orchard Core, the Los Angeles time zone, and the user admin
   (email admin@example.com, a password chosen outside git).
2. Check that the Shortcodes and Media features are enabled and that Localization is not, and that the media library
   holds the three pictures of the Blog recipe.
3. Create the one fake article, Spring Garden Tour, as the plan describes, and sign the recorder in.
4. Copy the site's data folder aside after each clip: the three recorded clips each publish the article, and each one
   starts from the state the previous one left.
5. Narrate, then record the clips in this order: the image, the options, the list. The slides need no recording.
