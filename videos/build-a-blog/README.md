# Build a Blog: Posts, Categories, Tags and a Menu

**YouTube:** not published yet · **Length:** 6:59 · **Feature:** [TheBlogTheme](https://docs.orchardcore.net/en/latest/getting-started/starter-recipes/)

This video builds a blog from the Blog recipe and The Blog Theme. It shows how the Blog, its posts, the Categories and
Tags taxonomies, and the Main Menu fit together, then adds a category, writes a post with a banner image, a category and
tags, and adds an item to the Main Menu. The title, description, tags and chapters YouTube shows are in the video's
metadata file.

The documentation pages it backs are the Lists, Taxonomies, Menu, Autoroute, Widgets and Resources pages of the modules,
and the page about the starter recipes and themes.

## Recording it again

The video is recorded on a **fresh site** with fake data only, so it needs no mask script. Every step of every clip,
with the exact actions, the values to type and what must be on screen, is in recording-plan.md in this folder.

1. Run a site that Auto Setup provisions with the **Blog** recipe: site name Orchard Core, time zone
   America/Los_Angeles, user admin, an email at example.com, and a password chosen outside git. The recipe enables every
   feature the video shows and creates the Blog, a first post, the Categories and Tags taxonomies and the Main Menu, so
   no feature has to be enabled and no data has to be seeded.
2. Sign the recorder in, stop the site, and keep a copy of its data folder aside: this is the first snapshot.
3. Narrate, then record the clips in the order they play. The tour comes first, since it shows the site before anything
   is added. The next clips each depend on the one before: the category, then the post (it uses the category), then the
   tags (they use the post), then the menu (its last step opens the page of the category, which lists the post).
4. The category, post and menu clips change the site. The plan lists the snapshots to take after the category and after the
   post, and the one to restore before another take of each clip.
5. Before assembling, check the clips and the finished video for private data, as the plan lists.
