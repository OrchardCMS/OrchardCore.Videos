Read only this file to record the video. In this file a selector stands for `scene.Page.Locator(...)`. Labels come from
the Orchard Core source at commit `92db4a83` (paths below are relative to `src/OrchardCore.Modules/`, except those that
start with `OrchardCore/`, `OrchardCore.Themes/` or `OrchardCore.Cms.Web/`, which are relative to `src/`); the line numbers
are those of that commit. The narration is in `storyboard.json`; narrate before recording (`narrate.py` is run by the
person who records, never by the author of this plan).

### The seed data (made outside the capture, after Auto Setup and `Recorder setup`)

The video edits one layer, **Welcome**, which has one widget, **Welcome note**, and a rule with no conditions. Create
both by importing this recipe: sign in, open **Tools**, **Deployments**, **JSON Import** (`OrchardCore.Deployment/AdminMenu.cs:18-30`),
set the editor to the text below, and select **Import** (`OrchardCore.Deployment/Views/Import/Json.cshtml`). The editor is CodeMirror, so set it
with a script instead of typing, to avoid auto-indent: on the page run
`document.querySelector('.CodeMirror').CodeMirror.setValue(<the text>)`, then select **Import**. The page answers
"Recipe imported successfully!" (`OrchardCore.Deployment/Controllers/ImportController.cs:185`).

```json
{
  "steps": [
    {
      "name": "Layers",
      "Layers": [
        {
          "Name": "Welcome",
          "Description": "A note for the pages a visitor starts from.",
          "LayerRule": {
            "Conditions": []
          }
        }
      ]
    },
    {
      "name": "content",
      "data": [
        {
          "ContentItemId": "4n3v6q8w2r5t7y9k1m0p3x5zbc",
          "ContentType": "Paragraph",
          "DisplayText": "Welcome note",
          "Latest": true,
          "Published": true,
          "Author": "admin",
          "LayerMetadata": {
            "Layer": "Welcome",
            "Zone": "Content",
            "RenderTitle": true,
            "Position": 1
          },
          "Paragraph": {
            "Content": {
              "Html": "<p>First time here? The About page tells you who writes this blog.</p>"
            }
          }
        }
      ]
    }
  ]
}
```

Why this shape: the `Layers` step creates the layer and keeps an empty `Conditions` list (`OrchardCore.Layers/Recipes/LayerStep.cs:63-66,89`);
the id of the rule is generated by the step. The `Paragraph` widget type and its `Content` field come from the Blog recipe
(`OrchardCore.Themes/TheBlogTheme/Recipes/blog.recipe.json:398-418`, `:759-773`).

Check the seed before the first take (nothing here is recorded):

- **Design**, **Widgets** lists three layers: **Always**, **Homepage** and **Welcome**; the **Content** zone lists the widget **Welcome note** with the badge **Welcome**.
- Selecting **Edit** on **Welcome** shows **Edit Layer - Welcome**, with the warning "No conditions found. Please add at least one condition." under **Rules**.
- `http://localhost:5010/` does not show the Welcome note (an empty rule is never true).

Then stop the site and copy `App_Data` and `state.json` aside as snapshot **S0**.

restore S0, start it, and record in the order above. The slide chapters (01, 02, 08) and the cards need no recording.

Keep the actions of a step shorter than its narration (about 2.5 words a second). The page of every clip opens before the capture with `scene.OpenAsync(...)`. The admin menu, the layers page and the
layer's edit page are the same pages in every take; each clip ends on the page its last step describes.

Selectors used by several clips (the markup is in the source):

- Admin menu: `#adminMenu` (`NavigationConstants.AdminMenuId`, `TheAdmin/Views/Navigation-admin.cshtml`). **Design** is a toggle button, **Widgets** is the link whose `href` ends with `/Admin/Layers`.
- The **Add** button above the list of conditions (the rule's own): the first `button[data-bs-target='#modalConditions']` of the page (`OrchardCore.Rules/Views/Rule.Summary.cshtml:12`).
- The **Add** button of a group: `li.list-group-item button[data-bs-target='#modalConditions']` (`Views/Condition.Summary.cshtml:27`). It exists only once the Any group exists, and it is the only one in a row.
- The dialog **Available Rules**: `#modalConditions` (`Views/ConditionsModal.cshtml:10`); wait for `#modalConditions.show` before typing. The **Filter** box is `#search-box` (`:15`). The filter runs on the `keyup` event (`OrchardCore.Rules/Assets/ts/conditions-modal.ts:29`), so type with `TypeAsync`; setting the value with a fill call filters nothing. It compares the text typed with the HTML of the card body (`:41-49`), which holds the title and the hint of the card.
- The fields of a condition editor carry the class name of the condition as a prefix, because the display driver builds its prefix from the model name (`OrchardCore/OrchardCore.DisplayManagement/Handlers/DisplayDriver.cs:13,75-84`). The names used below are therefore `AnyConditionGroup.DisplayText`, `UrlCondition.SelectedOperation` and `UrlCondition.Value`; the ids are the same with an underscore instead of the dot. A bare `#Value`, `#DisplayText` or `[name='SelectedOperation']` matches nothing.
- Nothing needs the **Save** button of **Edit Layer - Welcome**: selecting **Create** on a condition stores it at once (`OrchardCore.Layers/Controllers/LayerRuleController.cs:123-125`), and the **Save** button only stores the name and the description (`OrchardCore.Layers/Controllers/AdminController.cs:216-242`). No clip selects it.
- A card in the dialog: `#modalConditions .item` with the card's title as text; its button is `a.condition-thumbnail` labeled **Add** (`Views/Condition.Thumbnail.cshtml:8`). Selecting it loads the **Create Rule** page, so use `ClickAndWaitForNavigationAsync`.
- On a **Create Rule** page (`OrchardCore.Layers/Views/LayerRule/Create.cshtml:4`) the button **Create** is `button.create` (`:19`); selecting it loads **Edit Layer - Welcome** again, with the message "Condition added successfully." (`Controllers/LayerRuleController.cs:125`).
- Highlights are cleared (`ClearHighlightsAsync`) before every navigation.
