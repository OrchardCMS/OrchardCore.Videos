# Starter Recipes: Choose How Your Site Starts

**YouTube:** not published yet · **Length:** 5:31 · **Feature:** [guide:getting-started/starter-recipes](https://docs.orchardcore.net/en/latest/getting-started/starter-recipes/)

Every Orchard Core site starts from a recipe chosen on the Setup screen. This video explains what a recipe sets up,
shows the Recipe list of the Setup screen, and compares the starter recipes: Blank site, Headless site, Blog, Agency,
Coming Soon, and Software as a Service. It ends with how to match a recipe to a job, and where to change the result
after setup. The title, description, tags and chapters YouTube shows are in the video's metadata file.

## Recording it again

The video is recorded in two sessions, both on throwaway local sites with fake data only, so it needs no mask script
and no saved sign-in. The Setup screen clip is recorded first, on an Orchard Core site that has not been set up (no
Auto Setup). The front-end clips of Blog, Agency, Coming Soon and Software as a Service are recorded afterward, on one
site that Auto Setup installs with four tenants, one per recipe. No clip signs in or changes the site.

Everything a person needs to record it without deciding anything is in the recording plan of this folder: the two
sites, the Auto Setup values, the order of the clips, the exact actions of every step, and the checks for private data.
Open questions that a person must confirm on a running site are in the open questions file of this folder.
