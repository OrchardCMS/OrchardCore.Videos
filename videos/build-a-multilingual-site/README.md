# Build a Multilingual Site: Cultures, Translations and a Picker

**YouTube:** not published yet · **Length:** 6:14 · **Feature:** OrchardCore.Localization ([documentation](https://docs.orchardcore.net/en/latest/reference/modules/Localize/))

The video builds a small site in two languages, English and French. It enables the Localization, Content Localization
and Content Culture Picker features, adds the cultures of the site, makes the Article content type translatable,
translates the About page, and shows the language menu that lets visitors switch between the two versions. The title,
description, tags and chapters YouTube shows are kept in the video's metadata file.

## Recording it again

The video is recorded on a **fresh site** with fake data only, so it needs no mask script.

1. Set up the site as the recording plan says: Auto Setup with the Blog recipe, site name Orchard Core, time zone
   America/Los_Angeles, user admin with the address admin@example.com, and a password chosen outside git. The installed
   UI language of the operating system must be English (United States), because the first row of the culture table
   comes from it (the recording plan says how to check it).
2. Seed the site once, before the localization features are enabled: replace the placeholder text of the About page
   with the short English text given in the recording plan. Nothing else is created. Stop the site and copy its data
   folder and the saved sign-in aside; this is the starting copy of the first clip.
3. The clips depend on each other. Record them in this order, each one from the copy taken after the previous one:
   enable the features (02-enable), add the cultures (03-cultures), add the Localization part to Article (04-part),
   translate the page (05-translate), make The Default Theme current and look at the picker settings (06-picker), and
   switch languages on the site (07-try). The cultures and the part can be recorded in either order. The two slide
   chapters need no site.
4. The recording plan names every click, every typed value and the label's source in the Orchard Core code. Narrate
   the video first, then record, as the skill's recording guide explains. Check the contact sheet of every clip for real
   names or addresses before assembling.
