# The Admin: Find Your Way Around Orchard Core

**YouTube:** not published · **Length:** 5:03 · **Feature:** [OrchardCore.Admin](https://docs.orchardcore.net/en/latest/reference/modules/Admin/)

A tour of the admin of an Orchard Core site made with the Blog recipe: its start page, the menu and its sections, page
titles and the breadcrumb, quick navigation with Ctrl+K, the Content Quick Navigation feature, and the tools in the top
bar (Visit Site, the theme toggle and the user menu). The title, description, tags and chapters YouTube shows are in
the video's metadata file. The narration is in the storyboard, and everything a person needs to record the video is in
the recording plan of this folder.

## Recording it again

The video is recorded on a **fresh site** with fake data only (the content of the Blog recipe), so it needs no mask
script.

1. Run the CMS web application of Orchard Core with its own empty data folder outside both repositories, on port 5010,
   provisioned by Auto Setup: the **Blog** recipe, site name **Orchard Core**, time zone America/Los_Angeles, user
   **admin** with the email admin@example.com, and a password chosen outside git. No feature is enabled before
   recording: the clip 06-content enables Content Quick Navigation on camera.
2. Sign the recorder in once, outside the capture, as the skill describes. Stop the site and copy its data folder aside,
   together with the saved sign-in (snapshot A). Restore that copy before every full take, and before taking 05-quick or
   06-content again.
3. Narrate the video, then record the clips in the order 02-start, 03-menu, 04-pages, 05-quick, 06-content and
   07-topbar. Only 06-content changes the site (it enables a feature), and 05-quick needs that feature disabled. The
   slide chapters (01-glance and 08-recap) need no recording.
