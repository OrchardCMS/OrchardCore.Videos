# Launch a Coming Soon Page While You Build Your Site

**YouTube:** not published yet · **Length:** 4:00 · **Feature:** TheComingSoonTheme ([Starter Recipes](https://docs.orchardcore.net/en/latest/getting-started/starter-recipes/))

A site that is still being built can start with a Coming Soon page: a message with a launch date, a field for an
email address and social icons. The video shows why such a page helps, how to choose the Coming Soon recipe on the
Setup screen, what visitors see, how to change the message, the button and a social address, what a sign-up does
and where to set up the services it uses, and how to replace the page when the site launches. The title,
description, tags and chapters YouTube shows are in video.json.

## Recording it again

The video is recorded on a fresh site with fake data only (the site name Example Garden Supply, the user admin, an
address at example.com), so it needs no mask script. Its first clip shows the Setup screen, so that clip is recorded
on a site that is not installed, without Auto Setup and without a saved sign-in. The setup is then finished by
hand with the Coming Soon recipe, the recorder signs in once, and a copy of the site is kept as the starting point of
every other clip.

The clips are recorded in this order: choose the recipe (Setup screen), then, from the copy of the installed site,
the page visitors see, the reCaptcha settings, the Themes page, and last the clip that edits the page, since it is the
only one that changes the site. The slides and the opening and closing cards are drawn from the storyboard.

The site, the answers to the Setup screen, the values typed on camera, the order of the clips, which clips change
the site, and the exact actions of every step are in recording-plan.md. The questions a person has to confirm on a
running site are in OPEN-QUESTIONS.md. The password of the recording is chosen outside git and never written in this
folder.
