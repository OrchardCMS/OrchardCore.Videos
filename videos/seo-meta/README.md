# SEO Meta: Titles, Descriptions and Social Sharing Cards

**YouTube:** not published yet · **Length:** 5:15 · **Feature:** [OrchardCore.Seo](https://docs.orchardcore.net/en/latest/reference/modules/Seo/)

The video shows how the SEO module of Orchard Core sets the values that search engines and social networks read from a
page: the title, the description, the address and the pictures of a shared link. It enables the module, sets the
site-wide defaults in Social Meta Settings, attaches the SeoMeta part to a content type, and fills in the SEO tab of a
page. It ends with the order in which each value is chosen. The title, description, tags and chapters YouTube shows are
in the metadata file of this folder. The robots file of the site is the subject of another video.

## Recording it again

The video is recorded on a fresh site with fake data only, so it needs no mask script. It is an admin video: the
recorder shows the admin screens only, never the markup of a page.

1. Run the Orchard Core web project with its own empty data folder outside both repositories, provisioned by Auto Setup
   with the Blog recipe, the site name Orchard Core, the time zone America/Los_Angeles and the user admin. The SEO
   feature must be disabled when recording starts: the first clip enables it on camera. The video needs no seed data, because it uses
   what the Blog recipe creates: the About article and the pictures about-bg.jpg and home-bg.jpg of the Media Library.
2. Sign the recorder in and take the first snapshot of the site's data folder and sign-in. The commands to build and run
   the recorder are the ones of the video producer skill.
3. Narrate, then record the four clips in the order of recording-plan.md: enable the module, set the defaults, add the
   part to the Article type, edit the About article. Each clip changes the site, so recording-plan.md says which snapshot
   to take after each clip and which one to restore to record a clip again. The slides and the two cards need no
   recording.
4. Look at every contact sheet and scan the frames for private data, as recording-plan.md lists. The facts of the video
   that cannot be seen on screen, and the labels to confirm on a running site, are in OPEN-QUESTIONS.md.
