# Home Page: Choose What Your Site Shows First

**YouTube:** not published yet · **Length:** 3:34 · **Feature:** [OrchardCore.HomeRoute](https://docs.orchardcore.net/en/latest/reference/modules/HomeRoute/), with [OrchardCore.Autoroute](https://docs.orchardcore.net/en/latest/reference/modules/Autoroute/)

This video shows how a site owner or editor chooses the page that opens at the address of the site, and how to change
it. It covers the Home Route and Autoroute features, the Show homepage options setting of a content type, the Set as
homepage checkbox in the editor of a content item, and the Set homepage permission of a role. The title, description,
tags and chapters YouTube shows are in the metadata file next to this one.

## Recording it again

The video is recorded on a **fresh site** with fake data only, so it needs no mask script. The recording plan next to
this file lists every action, selector and source reference; this is the summary.

1. **The site.** A fresh Orchard Core site, provisioned by Auto Setup with the Blog recipe (site name Orchard Core,
   time zone America/Los_Angeles, user admin, a password chosen outside git). The recipe already enables Home Route and
   Autoroute and sets the Blog as the home page, so no feature is enabled and no setting is changed before recording.
2. **The seed.** One published Article called Welcome to Juniper Lane Studio, created by hand before the first take.
   Copy the site's data aside as the first snapshot.
3. **The order.** The clips about the features, about allowing a content type, and about the permission only read the
   site and can be recorded in any order. The clip that sets the home page starts from the first snapshot and changes
   the site; copy the data aside again afterwards as the second snapshot. The clip that changes the home page starts
   from the second snapshot. Restore the matching snapshot before every further take of these two clips.
4. **Hide the template box.** The settings page of the Autoroute part opens with a box that holds a template. An admin
   video never shows code, so the recording plan gives a short page script, kept outside git, that hides the box for the
   whole recording.
5. **Narrate, then record.** Generate the narration first: the recorder holds each step for the length of its voice.
