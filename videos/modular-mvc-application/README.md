# A Modular ASP.NET Core MVC Application With Orchard Core

**YouTube:** not published yet · **Length:** 5:38 · **Feature:** `guide:guides/create-modular-application-mvc` ([Creating a modular ASP.NET Core application](https://docs.orchardcore.net/en/latest/guides/create-modular-application-mvc/))

A developer video for the guide of the same name. It creates a web application and a module from the Orchard Core
templates, connects them with a project reference, and reads the code of both: `Program.cs` and the layout of the web
application, and the project file, manifest, controller, view and `Startup` class of the module. It explains how Orchard
Core finds the module, runs the application, and registers a route so that the module answers requests for the home
page. Terminal commands and code are slides; two short browser clips show the page the module serves. The title,
description, tags and chapters YouTube shows are in `video.json`.

## Recording it again

The video is recorded on a **throwaway MVC application** generated by the templates, with no fake data and no sign-in,
so it needs no mask script. It is not an Orchard Core CMS site: there is no Auto Setup, no `state.json`, no
`Recorder setup` and no `Recorder prepare`. `recording-plan.md` holds every command and every action.

1. In an empty folder outside both repositories, generate the projects with `dotnet new ocmvc` and `dotnet new
   ocmodulemvc`, and reference the module from the web application. Check the generated files against the table of the
   plan.
2. Run the web application over HTTP on `http://localhost:5010`, and point the recorder at it:

   ```bash
   dotnet run --project OrchardCore.Mvc.Web/OrchardCore.Mvc.Web.csproj --no-launch-profile --urls http://localhost:5010
   export VIDEO_ROOT=<repo>/videos/modular-mvc-application VIDEO_BASE_URL=http://localhost:5010
   ```

3. Narrate: `scripts/narrate.py videos/modular-mvc-application`, once the spellings of `OPEN-QUESTIONS.md` (question 3)
   are confirmed.
4. Record the two clips from two states of the code. `06-run` is recorded on the projects as generated. Then stop the
   application, add the route to `Startup.cs` and the heading to `Index.cshtml` (the edits are in the plan), run it again,
   and record `07-home`. Keep a copy of each state to record a clip again.
